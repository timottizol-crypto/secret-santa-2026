# Secret Santa 2026

Новогодний сайт для жеребьёвки Тайного Санты.

## Запуск
Откройте `index.html` в браузере телефона или компьютера. Интернет для работы жеребьёвки не требуется (Google Fonts при наличии интернета добавляет выбранные шрифты; системные шрифты остаются доступными без сети).

## Как работает
- Список участников уже заполнен.
- При первом старте создаётся случайное распределение без самоназначений.
- Каждый участник выбирает себя, видит только своё назначение и нажимает «Далее».
- После просмотра участник исчезает из списка выбора, а его получатель — из прокручиваемого списка доступных получателей.
- Назначения и список завершивших участников хранятся в `localStorage` браузера.

## Важно о приватности
Это рассчитано на передачу одного телефона из рук в руки. Результаты не отправляются на сервер, но это не защищает от человека, который специально откроет инструменты разработчика или данные сайта. Не очищайте данные браузера до завершения игры. Если открыть сайт на другом устройстве или в другом браузере, там будет отдельное распределение.

## GitHub Pages
Можно загрузить `index.html` в корень репозитория и включить GitHub Pages в Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
